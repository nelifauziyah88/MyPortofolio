A

General Description

Project-Based Learning (PBL) is a learning approach where students learn through real-world project exploration. In PBL, students collaborate in teams, conduct research, and present project results — working on projects that are relevant and meaningful.

The project developed is a Web-Based Game Top-Up Marketplace, accessible only via PC or laptop connected to the database through an internet connection. Application users are divided into two main roles: seller and buyer.

  • The seller can manage and control all data within the system.
  • The buyer can sign up, log in, browse the website, and make purchases.

b. Non-Functional Requirements

Source Code

Well-structured and easy to maintain by different developers, following standard conventions.

UI/UX

Interface must be intuitive and easy to use for both buyers and sellers.

Responsiveness

Runs smoothly and intended for use on Laptop/PC devices only.

Scalability

Supports addition of new products and users over time.

Modular Design

Easy to update and add products without affecting existing features.

User Security

Protects user data from unauthorized access.

C

User Identification & Access Rights

Seller
Admin — Full Access

The seller manages all aspects of the system, including transactions and products (game top-ups).

Access Rights

  • Product Management: can add, update, or delete game top-up products, including setting prices and descriptions.
  • Monitor transactions and track logged-in user activity.
  • View system error and bug reports.
Buyer
End User — Limited Access

The buyer is the end user who purchases game top-ups. They have limited access related to transactions and personal account management.

Access Rights

  • Place Orders: browse the game top-up catalog and make purchases.
  • Account Management: edit profile information such as email, username, profile photo, and phone number.
  • Payment: pay via QRIS, Dana, GoPay, and BNI.
