General Description

Geomarketia is a web-based geospatial market analysis platform designed to help business owners, investors, and local governments make smarter location decisions. Most existing GIS tools focus only on static mapping and location search — Geomarketia goes further by integrating dynamic market analysis including population density overlays, retail competition levels, and market saturation potential.

The platform serves three main business sectors: Retail, Food & Beverage (F&B), and Healthcare, providing spatial insights that replace intuition-based decisions with data-backed strategy.

  • Interactive Map Analysis — Visualize business locations with markers, radius selectors (1–5 km), and popup business info cards.
  • Cluster Area Analysis — Identify market concentration zones through spatial clustering and density heatmaps.
  • AI Chat Integration — Ask market analysis questions before and after purchasing a project dataset.
  • Project Marketplace — Browse, filter, purchase, and access geospatial analysis projects by sector and region.
  • Admin Dashboard — Manage projects, monitor transactions, and export sales reports to Excel.

b. Non-Functional Requirements

Performance

Main page and dashboard must load in ≤ 5 seconds on a normal connection; map filters must remain responsive without freezing the browser.

Security

User passwords stored as hashed values; dashboard and project access restricted to authenticated users only.

Reliability

No fatal errors during testing; data persists permanently in the database even after server restarts.

Usability

UI easy to understand for SME users; clear navigation flow with a responsive layout for both desktop and mobile.

Compatibility

Accessible on Chrome and Edge browsers at standard laptop screen resolutions.

User Roles & Access Rights

Admin
Admin — Full Access

The admin manages all geospatial projects on the platform, monitors user purchase transactions, and maintains the overall data ecosystem.

Access Rights

  • Add, edit, and delete market analysis projects and datasets.
  • View and manage all user purchase transactions and payment records.
  • Export sales and transaction reports to Excel (.xlsx).
  • Manage registered user accounts and platform content.
User
End User — Limited Access

Users are business owners, investors, or analysts who browse and purchase geospatial project datasets to perform location-based market analysis.

Access Rights

  • Browse & Search: explore available projects, filter by category, and view project details with map previews.
  • AI Chat: ask market analysis questions before and after purchasing a project.
  • Purchase & Pay: buy project datasets and complete payment through the platform.
  • Map Analysis: access interactive maps with business markers, radius selector, and location info popups.
  • Cluster Analysis: explore density heatmaps and spatial clustering statistics for deeper market insights.
D

Development Method

Geomarketia was developed using the Agile Software Development methodology, prioritizing an iterative, flexible, and collaborative approach to respond dynamically to evolving system requirements.

  • Requirements & Planning — Identified functional needs such as spatial data integration, interactive map visualization, and project marketplace features, organized by priority.
  • Analysis & Design — Transformed requirements into system architecture, GeoJSON data structures, and UI/UX prototypes using Figma.
  • Iteration / Development — Modular coding cycles using Next.js and Leaflet to dynamically render spatial location data and platform features.
  • Testing & Quality Assurance — Applied black-box testing to validate coordinate accuracy and platform responsiveness across devices.
  • Deployment — Migrated the codebase to a hosting server, making Geomarketia publicly accessible online.
  • Review — Evaluated system performance and spatial data accuracy to ensure results aligned with functional goals and user needs.
